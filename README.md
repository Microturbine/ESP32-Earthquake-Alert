# ESP32 EWS & QZSS Hybrid Decoder (WiFi / WebUI ブランチ)

ESP32のデュアルコアを活用し、地上（FM EWS）と宇宙（みちびき L1S）の両面から緊急事態を監視する、ハイブリッド災害警報デコーダーです。
本ブランチでは、WiFi機能を用いたリアルタイムステータス監視および、WebUIによる各種リモート設定・テスト機能、さらにWiFi経由でのプログラム書き込み（OTA）に対応しています。

---

## 主な特徴

- **ハイブリッド二重待機**: 
    - **FMラジオ EWS**: 64bps FSK信号をアナログ解析し、警報・地域・日時を抽出。
    - **みちびき L1S (災危通報)**: QZSS衛星からの生データ（サブフレーム）を捕捉・デコード。
- **QZSSデコード (災危通報解析の拡張)**:
    - **MT43 (DCR: 災危通報)**: 仕様書（IS-QZSS-DCR-016）に準拠。緊急地震速報（M・震度）や津波警報（高さ）のビット解析に加え、震央地名・津波予報区の日本語表示に対応。
    - **海上警報 (Category 14)**: 最大8ペア（Region 1〜8）の同時デコードに対応。テーブル定義を公式仕様書準拠の正式海域予報区名（例：「日本海北部及びオホーツク海南部」等）に改め、仕様にないコードを受信した際もコード番号でフォールバック表示します。
    - **MT44 (DCX: 拡張災危通報)**: Jアラート（国民保護情報）およびLアラート（自治体避難情報）の受信と解析に対応。マスク演算処理（1ULLシフト）の安全性を確保しています。
- **WebUI ダッシュボード**:
    - グラスモーフィズムを採用した美麗なダークモードUI（スマホ・PC対応）。
    - リアルタイムでFM周波数、RSSI、GPS時間、補足衛星数、アクティブな災害警報を自動更新表示（1.5秒ポーリング）。
    - **海上警報アコーディオン**: 複数海域の警報が同時に出た際、アコーディオン（`<details>`）で折りたたんでグループ表示し、ダッシュボードの縦伸びを防ぎます（リスト最大高 `180px` / スクロール対応 / 個別カウントダウンとヘッダー最大残り時間のリアルタイム同期）。
    - 模擬アラート（地震・津波・Jアラート・Lアラート・複数海上警報）のワンクリック発報、および任意の32バイト生パケット（16進数）の送信テスト機能を搭載。
    - Web上からFM周波数、音量、地域コード、接続先WiFi情報の変更・永続化が可能。
- **WiFi経由のファームウェア書き込み (OTA) [新機能]**:
    - **ArduinoOTA (IDE直接書き込み)**: Arduino IDEの「ポート」メニューにネットワーク上の本機 (`esp32-alert-decoder.local`) が自動検出され、USB同様に1クリックでコンパイル＆直接転送が可能です。
    - **WebUI OTA (ブラウザ書き込み)**: PC/スマホのブラウザから `http://[IPアドレス]/update`（または設定の「システム」タブ）を開き、コンパイル済みのバイナリファイル（`.bin`）をアップロードするだけで更新が完了します（進捗メーター・自動再起動・リダイレクト対応）。
- **WiFi 接続制御**:
    - 設定されたWiFiがあれば宅内ルーターへ自動接続（STAモード）。
    - WiFi未設定または接続タイムアウト（15秒）時は、自動でアクセスポイントモード（APモード：SSID `ESP32-Alert-Decoder`、IP `192.168.4.1`）として起動し、ブラウザからセットアップが可能。

## ハードウェア構成

### 1. 必要部品
- **ESP32 開発ボード**
- **RDA5807M** (FMラジオモジュール)
- **NEO-M8N** (GPSモジュール / FW 3.01以降推奨)
- **ST7789P3** (IPSカラー液晶モジュール / 76x284 バータイプ)
- **1.65Vバイアス回路** (音声入力用)

### 2. ピン接続

| ESP32 ピン | デバイス | 機能 | 備考 |
| :--- | :--- | :--- | :--- |
| **D19 / D18** | RDA5807M | SDA / SCL | I2C (Mutex保護) |
| **D22 / D23** | NEO-M8N | TXD / RXD | GPSデータ送受信 |
| **D4 (GPIO4)** | 音声入力 | ADC | バイアス回路経由 |
| **D14 / D13** | ST7789P3 | SCL / SDA | SPI (SCK / MOSI) |
| **D27 / D15 / D5** | ST7789P3 | RST / DC / CS | ※D17等の競合ピンを回避 |
| **D21** | ST7789P3 | BL | バックライト |
| **D2 (GPIO2)** | 本体LED | アラート表示 | 警報受信時に点滅（新しい警報の追加で5回点滅） |
| **GPIO0 (BOOT)** | BOOTボタン | 警報の手動クリア | 押下時にすべての警報とLEDの点滅状態を即座にリセット |

## ソフトウェアセットアップと操作

### 1. パーティション設定 (重要)
WiFi機能やWebサーバー、およびWiFi書き込み（OTA）用の予備領域確保のため、コンパイル後のバイナリサイズが標準のアプリ領域（1.2MB）を超過します。コンパイル・書き込み前に必ず以下の設定を行ってください。

1. Arduino IDEのメニューから **「ツール」 (Tools)** -> **「Partition Scheme」** を開きます。
2. **`Minimal SPIFFS (Large APPs with OTA)`**（または `Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)`）を選択します。
3. 検証および書き込みを行います。

> [!NOTE]
> 初回のみ、上記のパーティションスキーマを設定した状態でUSB経由で書き込む必要があります。2回目以降はWiFi経由でのアップデートが可能です。

### 2. 操作方法

#### WiFi経由での書き込み方法
- **方法A（Arduino IDE）**: 同一WiFi接続下で、IDEの「ツール」->「ポート」に表示される `esp32-alert-decoder at [IPアドレス]` を選択し、通常通り「書き込み」を行います。
- **方法B（WebUI）**: IDEメニュー「スケッチ」->「コンパイルしたバイナリを出力」で書き出した `.bin` ファイルを、ダッシュボードの「設定」->「システム」タブ内のアップローダーにドラッグ＆ドロップして更新します。

#### WiFiおよびWebUIへのアクセス
1. 起動時に液晶画面の3行目右側にIPアドレスが表示されます。
   - 初期状態、または接続失敗時：`IP:192.168.4.1` (APモード)
   - ルーター接続成功時：ルーターから割り当てられたIP (STAモード)
2. 同一ネットワーク内のPCまたはスマートフォンのブラウザから `http://[液晶に表示されたIP]/` にアクセスするか、`http://esp32-alert-decoder.local/` を開くとダッシュボードが表示されます。

#### シリアルコマンド (115200bps)
PCのシリアルモニター等から以下のコマンドを送信して設定することも可能です。
- **`help`** または **`?`** : 利用可能なコマンドと使い方のヘルプを表示
- **`status`** : 現在の受信状態（周波数、音量、RSSI、設定地域コード）を表示
- **`wifi [SSID] [パスワード]`** : WiFi接続情報を設定して保存し、デバイスを再起動
- **`80.0`** : 選局周波数 (MHz) を設定して保存
- **`v10`** : 音量調整 (0-15) を設定して保存
- **`area 13`** : ターゲット地域コード（例: 13=東京, 0=全域受信）を設定して保存
- **`test [43/44] [16進]`** : 指定した16進データでみちびきデコードをテスト
